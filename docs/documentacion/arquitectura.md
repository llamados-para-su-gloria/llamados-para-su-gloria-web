# Arquitectura del Sistema

## Proyecto

Sitio web oficial de la Iglesia Cristiana Llamados para Su Gloria

## Objetivo

Definir la arquitectura general del sistema, los componentes principales y la comunicación entre ellos.

## Tecnologías

- Frontend: Angular
- Backend: Spring Boot
- Base de datos: PostgreSQL
- Control de versiones: Git y GitHub
- Hospedaje:
  - Frontend: Netlify
  - Backend: Render
  - Base de datos: PostgreSQL (Render o proveedor compatible)
