# Diseño del Sitio Web

## Proyecto

Sitio web oficial de la Iglesia Cristiana
Llamados para Su Gloria

# Objetivos del diseño

El sitio debe transmitir:

- Cercanía.
- Confianza.
- Esperanza.
- Amor por la Palabra de Dios.
- Orden.
- Profesionalismo.

Debe ser una página sencilla, moderna y fácil de utilizar tanto en computadora como en dispositivos móviles.

# Filosofía de diseño

- Diseño limpio.
- Mucho espacio entre elementos.
- Fotografías grandes.
- Poco texto por sección.
- Colores suaves.
- Navegación sencilla.
- Diseño responsive desde el inicio.

# Paleta de colores

## Principal

Azul institucional.

Uso:

- Header
- Botones principales
- Enlaces importantes

## Secundario

Azul grisáceo.

Uso:

- Tarjetas
- Íconos
- Fondos suaves

## Fondo

Blanco.

## Fondo alternativo

Gris muy claro.

## Texto

Gris oscuro.
