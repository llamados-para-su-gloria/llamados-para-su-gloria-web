# Wireframe — Llamados para Su Gloria

## Diseño general

### Paleta inicial
- Azul profundo: color principal del logo.
- Azul grisáceo: fondos secundarios.
- Blanco: fondos principales y lectura.
- Gris oscuro: texto.
- Dorado/beige.

### Tipografía
- Títulos: PENDIENTE.
- Texto: PENDIENTE.

### Botones principales
- Fondo azul profundo.
- Texto blanco.
- Bordes ligeramente redondeados.
- Tamaño suficiente para tocar en celular.
